# Support

DocSync Guard is a small open-source maintainer tool. The best place to ask for help is GitHub Issues.

## Before Opening an Issue

Please check:

- the README quick start
- `examples/basic`
- existing open issues
- the latest release notes

## Good Support Requests

Helpful support requests usually include:

- the `docsync.yml` file
- the smallest relevant source and target Markdown snippets
- the command you ran
- the terminal, Markdown, or JSON report output
- your DocSync Guard version

## What This Project Can Help With

- missing section reports
- stale section cache behavior
- broken local link or image reports
- terminology drift configuration
- GitHub Action setup

## What This Project Does Not Provide

DocSync Guard does not provide translation services, translation quality review, remote URL monitoring, or AI-generated documentation rewrites.
