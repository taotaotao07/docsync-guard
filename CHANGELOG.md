- Add `docsync.yml` configuration loading.
- Add terminal, Markdown, and JSON reports.
- Add heading structure checks for missing translated sections.

- Add optional `.docsync-cache.json` section hash checks for stale source sections.
- Add the DocSync Guard GitHub Action with GitHub Actions step summary output.
- Add README, Chinese README, SPEC, CONTRIBUTING, LICENSE, and runnable examples.
